# Spelet 2048 för prutten
## Kravspecifikation för betyg A från canvas
- Spelplan
    - 4x4 rutnät
    - Spelet startar med två brickor
    - Båda startbrickor har värdet 2 eller 4 och placeras slumpmässigt

- Mekanik 
    - Brickorna går att flytta, vänster, höger, upp och ner
    - Summan av brickorna adderas när de krockar
    - Lägg en bricka med värdet 2 eller 4 efter varje drag

- Extra
    - Spelslut när inga drag är möjliga
    - Omstart för spelet
    - Algoritm som slumpar drag ut spelaren
    - Ångra drag
    - Spara resultat i en json fil
